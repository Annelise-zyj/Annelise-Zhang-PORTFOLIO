GitHub Pages upload package

Upload every item inside this folder to the repository's publishing root, including the hidden .nojekyll file. Keep the folder structure as-is.

The package is a production build of the six-page portfolio. It includes the HTML pages, generated CSS/JavaScript, images, photography, audio, and transparent contact video. Do not upload the source project or node_modules for GitHub Pages.

Some project films are streamed from their existing external video URLs, so playback depends on those providers remaining available and allowing browser playback.
